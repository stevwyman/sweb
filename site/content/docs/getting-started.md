This site is generated by **Hugo** with the [Docsy](https://www.docsy.dev/) theme. Login uses **Auth.js** with an encrypted JWT cookie — there is no database.

## Local preview

1. Run `podman compose up` from the project root.
2. Open [http://localhost:3000](http://localhost:3000).
3. Public pages such as this one do not require a session.
4. [Members pages](/members/) redirect to [login](/login) until you sign in.

Demo account: `demo@example.com` / `changeme-demo`

## Edit content

Change Markdown under `site/content/`. The Hugo container watches that folder and writes HTML into `static-site/`. Auth.js in the `web` container serves those files.
